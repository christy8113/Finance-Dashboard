## 🚀 Features

- Dashboard summary (Balance, Income, Expenses)
- Interactive charts (Recharts)
- Transaction management
- Role-based UI (Admin / Viewer)
- Insights generation
- Responsive UI with Tailwind CSS
- Local storage persistence

## 🛠 Tech Stack

- React.js
- Tailwind CSS
- Recharts
- Context API
